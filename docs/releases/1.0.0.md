# ForwardMeasure OpenWorkflow 1.0.0

Initial unified release targeting the digest-pinned Open Workflow `1.0.3` specification.

Highlights include governed immutable workflow revisions, independent approval/publication,
tenant-isolated AuthZEN enforcement, interchangeable Pekko and Kafka Streams engines, PostgreSQL
and Cassandra Pekko persistence, complete protocol adapters, canonical query/history, shared Studio,
three framework hosts, generated clients, and hardened Helmfile profiles.

Upgrade from standalone OKS/OAE deployments follows
`docs/migration/standalone-migration-map.md` and the machine-constrained import/retirement evidence.
Do not translate a live engine's internal state; allow existing executions to complete in their
original engine unless a separately proven migration is named in the map. Backup, rollout, rebuild
and rollback procedures are in `docs/operations.md`.

Known compatibility boundary: the product remains pinned to Open Workflow `1.0.3`. Moving to a
later specification requires an explicit manifesto amendment.
